# ThymeleafとHTMLに関するメモ

今までなんとなくしか理解していなかったので、調べて解決したことはメモしておく

## Thymeleaf

**th:field:** `th:field="${オブジェクト}"`
- オブジェクトの内容をもとに、id, name, valueを自動生成
- idとnameはそのオブジェクトの名前
- valueは実際に入力されている値
- オブジェクトがないとエラーになる

## HTML

**labal:** `<label for="">`
- forと対応するidと紐づけをする
- クリック範囲をラベルテキストに拡大できたり
- アクセシビリティへの対応やセマンティックHTMLといった部分で、クリック範囲の拡大が必要なくても記述しておいたほうがいい
