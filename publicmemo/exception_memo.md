# 概要
例外処理を作るときの考え方をまとまる  
テストを作ることも一緒に考える(ちゃんと動くかどうかを確かめるため)  
空から考えるのはさすがに厳しいので、とりあえず型を使ってやってみる  
改善の余地大ありなので、修正していく
# 例外処理を作る流れ
1. 例外処理をする目的を決める
    - この処理は例外をキャッチしてアプリを止めない
    - 何度かリトライさせて、それでもだめなら諦める など
2. どこからどこまでの範囲なのかを決める
    - どこまでの処理をキャッチするのかを、クラスの目的と照らし合わせて考える
3. 必要になる要素を挙げていく
    - 箇条書きでとりあえず思いつくものをたくさん
4. 1~3の要素を照らし合わせながら必要な要素だけを取り出す
5. 実際に書いていく
